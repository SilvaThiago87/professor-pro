# Professor Pro — Landing Page

Landing page responsiva de demonstração para a startup Professor Pro, inspirada em uma identidade visual geométrica de influência Bauhaus.

## Como abrir

Abra `index.html` no navegador. Não há etapa de build nem backend. A página usa HTML, CSS e JavaScript puro.

## O que funciona

- Navegação responsiva e links para as seções da página.
- Catálogo visual de seis skills de ensino.
- Laboratório que gera e permite copiar prompts pedagógicos personalizados.
- Acessibilidade básica e atenção a movimento reduzido.

**Importante:** o laboratório gera apenas o texto do prompt e não chama nenhuma API de IA. As atividades finais devem ser produzidas em uma ferramenta externa e revisadas por um professor. Não existe cadastro, pagamento nem coleta de dados na página.

## GitHub Pages

Arquivos desta pasta podem ser publicados como um site estático. Em um repositório com Pages configurado para publicar a branch `main` e a raiz `/`, a URL segue o caminho desta pasta (`/professor-pro/`).

## Arquivos

- `index.html`
- `assets/styles.css`
- `assets/app.js`
- `assets/logo.svg` — versão vetorial simplificada do símbolo fornecido como referência visual
